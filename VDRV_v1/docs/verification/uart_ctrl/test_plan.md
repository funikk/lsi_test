# UART Control Block テスト計画

## 概要
`uart_ctrl` ブロックの機能検証計画を記述する。このブロックはホストから送信されたUARTのシリアルデータをデコードし、コマンドパケット（SET_STEP, START_SEQ, STOP_SEQなど）として後段のモジュールに伝達する役割を持つ。

## 検証項目

1.  **UART受信とデコード**
    *   ボーレート生成とデータサンプリングが正しく行われるか。
    *   プリアンブル（ヘッダ） `0xAA 0x55` を正しく検出できるか。
2.  **コマンドパケットのパース**
    *   コマンドIDの識別（SET_STEP, START_SEQ, STOP_SEQ）。
    *   コマンドに応じたペイロードの抽出（例：SET_STEP時のステップID、ステート、デュレーション）。
3.  **チェックサム検証** (必要に応じて)
    *   （tb_uart_ctrlの現状の実装ではヘッダとコマンド、ペイロードの順次送信のパースを確認する。）

## テストシナリオ

1.  **初期化**
    *   リセット解除後、UARTモジュールが受信待機状態になることを確認する。
2.  **SET_STEP コマンドの受信**
    *   `0xAA 0x55 0x01` に続いて、ペイロード（ステート、ID、デュレーション）を送信する。
    *   `cmd_set_step` フラグがアサートされ、適切な値が後段へ出力されることを確認する。
3.  **START_SEQ コマンドの受信**
    *   `0xAA 0x55 0x02` を送信し、`cmd_start_seq` フラグがアサートされることを確認する。
4.  **波形確認**
    *   VCDファイルを出力し、受信データから各信号へ変換される過程を波形で視覚的に確認する。
