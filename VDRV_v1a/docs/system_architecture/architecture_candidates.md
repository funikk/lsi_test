# VDRV_v1a アーキテクチャ検討候補案仕様書 (Architecture Candidates Specification)

## 1. 概要 (Overview)

本ドキュメントは、RISC-V CPU と MAC アレイ / CRC-RS 高トグルストレスコアを搭載した LSI テストベッド **`VDRV_v1a`** における負荷生成アーキテクチャおよびシーケンス制御方式の比較・評価を行う設計書です。

電源網の動的電圧降下（IR-Drop）および急峻な過渡電流変動率（$di/dt$）をチップ上で自在に励起・観測するために、複数の負荷源と制御方式を検討・採用しました。

---

## 2. 負荷生成エンジンの選定比較

| 項目 | 方式 1: 単一暗号コア (従来型) | 方式 2: シストリック MAC アレイ | 方式 3: 並列 CRC + RS 多項式ミキサ | 方式 4: ハイブリッド構成 (**本設計採用**) |
| :--- | :--- | :--- | :--- | :--- |
| **主な電流特性** | 一定周期のパイプライン反復トグル | 空間的演算伝搬、算術加算・積和トグル | 高密度なビットランダムトグル、GF(2^8)非線形反転 | **算術積和 (MAC) と高頻度トグル (CRC) の合成刺激** |
| **トグル率分布** | 中〜高 (データパス依存) | 高 (乗算器・アキュムレータ部集中) | 極めて高 (多項式帰還・RSミキサ部) | **超広帯域 (局所集中 + 全面均一拡散)** |
| **面積効率** | S-Box等のLUT面積大 | 乗算器マトリクス主体の高集積 | シフトレジスタ・XORツリー主体で超小型 | **高密度かつ多段階の電力スケール調整が可能** |
| **柔軟性** | 鍵・平文依存 | 行列サイズ・演算サイクル可変 | 多項式・チャネル数可変 | **独立起動・同時起動の自由な組み合わせ** |

### 採用理由
`VDRV_v1a` では、方式 4（ハイブリッド構成）を採用しました。シストリック MAC アレイ (`mac_load_core`) による大電流算術演算トグルと、Reed-Solomon 多項式ミキサ付き並列 CRC (`crc_load_core`) による広帯域ビット反転トグルを組み合わせることで、単一のエンジンでは再現できない多様な電源ノイズスペクトラムを生成できます。

## 3. シーケンス制御アーキテクチャの比較

### 候補案 A: ハードウェア直結シーケンス制御 (HW-Direct Sequencer)
* **概念**: `load_sequencer` がハードウェアタイマー（50サイクル単位）に基づき、CPU を介さず直接 `mac_load_mode_en` / `crc_load_mode_en` をドライブ。
* **メリット**:
  1. CPU がスリープ（WFI）状態を維持できるため、CPU ノイズの混入しない純粋な負荷エンジン単体波形を測定可能。
  2. 1 サイクル単位で正確な保持時間制御が可能。
* **デメリット**:
  1. CPU の命令実行開始・終了に伴う急峻な電流変化を組み合わせにくい。

### 候補案 B: CPU 割込み協調シーケンス制御 (IRQ-Assisted Sequencer)
* **概念**: `load_sequencer` がステップ切り替わり時に CPU 割込み (`irq[3]`) を発火。ファームウェアが割込みハンドラ内で MMIO レジスタを操作して負荷モードを動的に遷移。
* **メリット**:
  1. 割込み受付とコンテキスト退避に伴う急激な $di/dt$ スパイクを意図的に発生可能。
  2. ソフトウェア制御による柔軟なアルゴリズム追従。
* **デメリット**:
  1. 割込み応答レイテンシ（数マイクロ秒）のジッターが発生。

### 採用アーキテクチャ: デュアルモード・ハイブリッド制御
`VDRV_v1a` では両方式を統合し、`load_sequencer` のコントロールレジスタ `REG_CTRL[0]` (`irq_mode`) により、テスト目的に応じて「ハードウェア直結モード (`hw_direct_active`)」と「CPU 割込み協調モード」をソフトウェアから切り替え可能としました。
これにより、純粋な静的電圧降下プロファイルの測定と、急峻な過渡 $di/dt$ ノイズの測定の両方に対応します。
