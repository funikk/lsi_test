# PicoRV32 RISC-V CPU 単体検証計画書 (`blocks/picorv32_cpu`)

## 1. 検証目的 (Verification Objectives)
`picorv32_cpu` は、VDRV_v1a システムの主制御プロセッサである。
本計画書では、単体テストベンチ（`tb/tb_picorv32.v`）を用いて以下の基本動作と機能健全性を確認する。

1. リセット解除後の正常起動とリセットベクタ（`0x0000_0000`）からの命令フェッチ動作。
2. メモリバスインターフェース（`mem_valid`, `mem_ready`, `mem_addr`）のハンドシェイクプロトコル整合性。
3. トラップ未発生（`!trap`）の継続的確認。

---

## 2. 検証項目一覧 (Test Matrix)

| テストID | テスト項目名 | 検証内容と手順 | 期待される結果 (Pass Criteria) |
| :--- | :--- | :--- | :--- |
| **TEST 1** | リセット解除 & 命令フェッチ検証 | 1. リセットをアサート後に解除。<br>2. 最初の `mem_valid` アサートを待機。<br>3. メモリアドレスが `0x0000_0000` であることを確認。<br>4. ダミーNOP命令（`0x00000013`: `addi x0, x0, 0`）を供給。 | リセット解除後に命令フェッチアドレス `0x0000_0000` が発行され、トラップが発生せず正常実行を継続すること。 |

---

## 3. テストベンチ設計 (`tb/tb_picorv32.v`)

- **クロック周期**: 10ns (100MHz)
- **ダミーメモリ応答**: `mem_valid` に対して1サイクル遅延で `mem_ready = 1` および `mem_rdata = 32'h00000013` (NOP) を返答。
- **合否判定**: 10サイクルのNOP実行後、`trap` がアサートされていないことを確認。
