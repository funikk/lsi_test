# RISC-V CPU コア仕様書 (`picorv32`)

## 1. 概要

本プロジェクトでは、Yosys/Verilog オープンソースエコシステムで広く検証されている 32-bit RISC-V CPU コア **PicoRV32** を採用しています。
命令バスとデータバスが完全に独立した**ハーバード・バス・インタフェース**として構成されています。

---

## 2. モジュール設定パラメータ

| パラメータ名 | 設定値 | 説明 |
| :--- | :--- | :--- |
| `ENABLE_COUNTERS` | `1` | サイクル・命令カウント（`rdcycle`, `rdinstret`）を有効化 |
| `ENABLE_COUNTERS64` | `1` | 64-bit カウンタ拡張 |
| `ENABLE_REGS_16_31` | `1` | フル 32 本の汎用レジスタセット (`x0` - `x31`) を使用 |
| `ENABLE_REGS_DUALPORT` | `1` | デュアルポートレジスタファイル使用 |
| `TWO_STAGE_SHIFT` | `1` | シフタ演算の2段構成 |
| `BARREL_SHIFTER` | `0` | バレルシフタ無効化（エリアサイズ最適化） |
| `COMPRESSED_ISA` | `0` | RV32C 16-bit 圧縮命令無効化 (標準 RV32I 32-bit 命令のみ) |
| `ENABLE_MUL` / `DIV` | `0` | ハードウェア乗除算器無効化 |
| `PROGADDR_RESET` | `0x0000_0000` | リセット直後の命令フェッチ開始アドレス |
| `STACKADDR` | `0x0000_0800` | スタックポインタ (`sp`) 初期設定値 (2048バイト) |

---

## 3. インタフェース信号仕様

### 共通 / 制御ピン
- `clk`: システムクロック入力
- `resetn`: アクティブ・ロー リセット入力
- `trap`: CPU トラップ出力（未定義命令実行時・バスエラー時にハイ出力）

### 命令バス (`IMEM` 接続用)
- `mem_instr`: 常に `1` （命令フェッチであることを示す）
- `mem_valid_instr`: 命令要求有効フラグ
- `mem_ready_instr`: 命令メモリ応対応答（`IMEM` からの ack）
- `mem_addr_instr[31:0]`: フェッチ対象の命令アドレス
- `mem_rdata_instr[31:0]`: 命令メモリからの 32-bit 命令データ

### データバス (`DMEM` / MMIO 接続用)
- `mem_valid`: データ転送要求有効フラグ
- `mem_ready`: データレスポンス完了フラグ
- `mem_addr[31:0]`: データアクセス対象アドレス
- `mem_wdata[31:0]`: ライトデータ
- `mem_wstrb[3:0]`: バイト有効ストローブ (1111: Word, 0011: Half, 0001: Byte)
- `mem_rdata[31:0]`: リードデータ

---

## 4. トラップおよび例外

以下の場合、`trap` ピンが `1` にアサートされ、CPU は実行を停止します：
- 未定義の RISC-V 命令を解読・実行しようとした場合
- アライメント違反のメモリ読み書きを実行した場合
- `ebreak` / `ecall` 命令を実行した場合
