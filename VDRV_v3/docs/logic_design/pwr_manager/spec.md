# Power Manager (`pwr_manager`) 仕様書

## 1. 概要
`pwr_manager` は、VDRV_v3 の各タイル行（電源ドメイングループ `PD_ROW[g]`）の電源投入・遮断を制御する電源管理モジュールです。
2段階パワースイッチ（Trickle / Main）のシーケンス制御、アイソレーション（Isolation）制御、電源ドメインリセット制御、および複数ドメイン間のスタガー投入スケジューリングを行います。
また、突入電流ストレス評価のための `UNSAFE_MODE`（一斉・即時投入）および Load Sequencer からのハードウェア直接制御（HW-Direct Mode）をサポートします。

## 2. パラメータ
| パラメータ | デフォルト値 | 有効範囲 | 説明 |
|:---|:---:|:---:|:---|
| `G` | 2 | 1 〜 8 | 電源グループ数（タイル行数） |

## 3. インターフェース

### 3.1 クロック・リセット
| 信号名 | 方向 | 幅 | 説明 |
|:---|:---:|:---:|:---|
| `clk` | input | 1 | システムクロック（立ち上がりエッジ） |
| `rst_n` | input | 1 | 非同期リセット（active-low） |

### 3.2 MMIOスレーブインターフェース (32-bit ワード)
| 信号名 | 方向 | 幅 | 説明 |
|:---|:---:|:---:|:---|
| `mmio_valid` | input | 1 | アクセス要求有効信号 |
| `mmio_addr` | input | 8 | バイトアドレスオフセット（下位2bitは常に0） |
| `mmio_wstrb` | input | 4 | バイト書き込みイネーブル（0: Read, 非0: Write） |
| `mmio_wdata` | input | 32 | 書き込みデータ |
| `mmio_rdata` | output | 32 | 読み出しデータ（レジスタ出力） |
| `mmio_ready` | output | 1 | アクセス応答（1サイクルパルス） |

### 3.3 ハードウェア直接要求 (Load Sequencer 連携)
| 信号名 | 方向 | 幅 | 説明 |
|:---|:---:|:---:|:---|
| `hw_direct_active` | input | 1 | 1のとき `hw_pd_req` を `PD_REQ` の代わりに実効要求として使用 |
| `hw_pd_req` | input | 8 | ハードウェア要求マスク（下位Gビットを使用） |

### 3.4 物理スイッチ・アイソレーション・リセット制御（すべてFF出力、active-high）
| 信号名 | 方向 | 幅 | 説明 |
|:---|:---:|:---:|:---|
| `sw_trickle_en` | output | G | 弱スイッチ（Trickle）イネーブル |
| `sw_trickle_ack` | input | G | Trickle スイッチチェーン完了応答 |
| `sw_main_en` | output | G | 主スイッチ（Main）イネーブル |
| `sw_main_ack` | input | G | Main スイッチチェーン完了応答 |
| `iso_en` | output | G | アイソレーションイネーブル（リセット時: 1） |
| `pd_rst_n` | output | G | 電源ドメイン内部リセット（リセット時: 0、active-low） |
| `pd_on` | output | G | 電源ON完了ステータス（状態がONのグループ） |

## 4. レジスタマップ

| オフセット | レジスタ名 | 属性 | リセット値 | 説明 |
|:---|:---|:---:|:---:|:---|
| `0x00` | `PD_REQ` | RW | `0x00000000` | [G-1:0] グループごとのソフトウェア電源ON要求 |
| `0x04` | `PD_STATUS` | R | `0x00000000` | [7:0] ON状態、[15:8] 遷移中、[23:16] 実効要求 |
| `0x08` | `T_TRICKLE` | RW | `0x00000010` | [15:0] Trickle投入後の最小待ちサイクル（リセット値: 16） |
| `0x0C` | `T_MAIN` | RW | `0x00000010` | [15:0] Main投入後の最小待ちサイクル（リセット値: 16） |
| `0x10` | `STAGGER` | RW | `0x00000000` | [15:0] ドメイン順次投入の間隔サイクル（0: 同時投入） |
| `0x14` | `PD_ORDER` | RW | `0x76543210` | 4bit×8エントリの投入順序指定（エントリkは [4k+3:4k]） |
| `0x18` | `UNSAFE_MODE` | RW | `0x00000000` | [0] 1: TrickleとMainを同時投入・Ack待ち省略 |

## 5. グループFSM動作仕様

各グループは独立した状態遷移マシンを持ちます。

```text
       +-------------------------------------------------------+
       |                                                       |
       v                                                       |
    [ OFF ] --(起動)--> [ TRICKLE ] --(Ack&Timer)--> [ MAIN ]  |
       ^                   (UNSAFE)                     |      |
       |                      +-------------------------+      |
       |                                                |      |
    [ SW_OFF ] <--(2cyc)-- [ ISO ] <--(実効要求=0)-- [ ON ] <-+ (4cyc)
       |                                                ^
       +-----------------(2cyc)-------------------------+
                                                     [ RST_REL ]
```

1. **通常電源投入**:
   - `OFF`: スケジューラから起動されると `TRICKLE` へ遷移（`sw_trickle_en=1`）。
   - `TRICKLE`: `sw_trickle_ack` がアサートされ、かつ `T_TRICKLE` サイクル経過後 `MAIN` へ遷移（`sw_main_en=1`）。
   - `MAIN`: `sw_main_ack` がアサートされ、かつ `T_MAIN` サイクル経過後 `RST_REL` へ遷移（`pd_rst_n=1`）。
   - `RST_REL`: 4サイクル待機後、`ON` へ遷移（`iso_en=0`、アイソレーション解除）。
2. **通常電源遮断**:
   - `ON`: 実効要求が0になると `ISO` へ遷移（`iso_en=1`、アイソレーション有効化）。
   - `ISO`: 2サイクル後 `SW_OFF` へ遷移（`pd_rst_n=0`、ドメインリセットアサート）。
   - `SW_OFF`: 2サイクル後 `OFF` へ遷移（`sw_trickle_en=0`, `sw_main_en=0`、スイッチ遮断）。
3. **UNSAFE_MODE**:
   - `OFF` から `MAIN` へ直接遷移し、`sw_trickle_en` と `sw_main_en` を同一サイクルでアサート。
   - Ack待ちをバイパスし、1サイクル後に `RST_REL` へ遷移。

## 6. 投入スケジューラ仕様
- 実効要求が1かつ状態がOFFのグループを「待ち」グループとして検出します。
- `STAGGER > 0` かつ `UNSAFE_MODE == 0` の場合、`PD_ORDER` のエントリ（k=0..7）を順次走査し、待ちグループを1つずつ起動します。1つ起動した後は `STAGGER` サイクル待機してから次のグループを起動します。
- `STAGGER == 0` または `UNSAFE_MODE == 1` の場合、すべての待ちグループを同一サイクルで一斉起動します。
- G以上の無効なグループエントリはスキップされます。
