# VDRV_v3 アーキテクチャ検討記録

大規模化の方針を検討した結果の記録。詳細な仕様は [spec_top.md](spec_top.md) を参照。

| 論点 | 検討した案 | 採用した案 | 理由 |
|:--|:--|:--|:--|
| 目標規模 | 10万〜100万 / 100万〜1000万 / 1000万超 | 10万〜100万 | 解析ツールの機能評価が目的で、容量限界のテストは主目的ではない |
| 規模の稼ぎ方 | 負荷タイルのアレイ / 外部IP（CVA6など）の取り込み / マルチコアCPU | 負荷タイルのアレイ（CPUは1個） | 電源ドメイン・活性率・位置を制御しやすく、検証も容易 |
| タイル構成 | 均一 / 異種混在 / 均一＋一部異種 | 均一＋端に異種列 | 対称性のチェックをしやすく、SRAMや低活性領域も評価できる |
| SRAM | ラッパーで差し替え / FFのまま / 使わない | ラッパーで差し替え | RTLがPDKに依存しない |
| 電源ドメイン | タイル群ごと / タイルごと / 多電圧 / 1つ | タイル群（行）ごと、単一電圧 | UPFを複雑にせず、突入電流とドメイン間の干渉に集中できる |
| パワースイッチ制御 | 2段階＋レジスタ設定 / 1本のイネーブル / 一斉投入のみ | 2段階（trickle→main）＋待ち時間・順序・UNSAFEモード | 同じネットリストで良い例と悪い例を作れる |
| 負荷制御 | 2層構成 / シーケンサの分解能を上げる / ファームウェアで制御 | 2層構成 | シナリオの切り替えとサイクル単位の精度を両立できる |
| クロック | 単一＋ICG / 複数クロック / ICGなし | 単一クロック＋タイルごとのICG | 大きなdi/dtを作れて、CDCの検証が不要 |
| 信号線EM | 専用の構造 / 自然に発生するもの / 物理側のみ | 専用の構造（ON/OFF可） | あり / なしを比較できる |
| シナリオの起動 | ピンで選んで自動実行 / UART / ファームウェア | ピンで選んで自動実行＋マーカー＋シグネチャ | ベクタの生成が短く、確実になる |
| 物理階層 | フラット＋境界FF / ハードマクロ / 完全フラット | フラット＋境界FF | 将来ハードマクロ化できる余地を残す |
| ローカル検証 | 小規模でPnRまで / RTL simまで / 本番規模 | 2×2でPnRまで（UPFなし）＋商用向けの雛形 | オープンソースEDAはUPFのスイッチを扱えないため |
