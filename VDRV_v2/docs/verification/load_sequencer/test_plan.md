# Load Sequencer Block テスト計画

## 概要
`load_sequencer` ブロックの機能検証計画を記述する。このブロックは、定義されたステップシーケンスに従い、CPUおよびAESの負荷状態の制御や割り込み生成を行う。

## 検証項目

1.  **プログラミングと設定**
    *   最大16ステップのRAMテーブルへの書き込みが正しく行えるか。
    *   総ステップ数やシーケンス有効化フラグなどのレジスタ設定。
2.  **シーケンス実行とタイマー**
    *   0.5us のティックタイマーに基づくステップのデュレーション管理。
    *   各ステップにおける負荷状態（`cpu_load_state`, `aes_load_mode_en`）の遷移。
3.  **割り込み機能**
    *   IRQモード0（シーケンス完了時）とIRQモード1（ステップ完了時）の切り替え。
    *   適切なタイミングでの割り込み（`cpu_irq`）のアサート。

## テストシナリオ

1.  **初期化とステップ設定**
    *   リセット解除後、コマンドを用いてステップ0（AES負荷）とステップ1（CPU負荷）のプログラミングを行う。
2.  **レジスタアクセス**
    *   メモリバス経由でシーケンサの制御レジスタ（`0x8000_0100`）へアクセスし、`total_steps=1`、`seq_enable=1`、`irq_mode=1` に設定する。`SEQ_CTRL` のbit[0]がIRQ_MODE、bit[1]がSEQ_ENABLEであることを確認する。
3.  **シーケンス実行の観察**
    *   設定したデュレーション（2ティック＝1us等）の経過後にシーケンスが進行し、状態遷移が行われることを確認する。
    *   VCD波形を通じて状態の切り替わりと割り込みの発生タイミングを検査する。
